# Shared Data

Curated datasets and reference collections shared across
`machine_learning/` and `clustering_taxonomic_placement/` (and, for
`contigs/`, produced by `manual_curation_annotation/`).

- **`contigs/`** — the 510 curated candidate contigs and intermediate
  filtering stages, generated by
  `manual_curation_annotation/notebooks/filtering_snakemake_contigs.ipynb`
  (`contigs_all.fasta` → `contigs_all_test.fasta` → `contigs_all_deduplicated.fasta`
  → `contigs_non_cellular.fasta` → `contigs_non_cellular_filtered.fasta`).
- **`domain_sci_input/`** — domain-scientist-provided ground truth and
  category annotations, plus the raw NCBI Virgaviridae sequences used to
  build the ML reference set. Trimmed to only the files actually used by
  the notebooks/scripts in this repo — see `machine_learning/README.md`'s
  migration notes and the migration report for what was dropped and why
  (mostly superseded intermediate versions of the same ground-truth/category
  spreadsheets).
- **`non-virga_representatives/`** — 1,398 NCBI viral representatives
  (duplicated at the genus level) used for the model's external
  non-*Virgaviridae* validation test, plus the DIAMOND-TPDB2-filtered subset
  actually fed to the model (`references/run_diamond_pipeline.py` produces
  the latter from the former).
- **`tobamo/`** — the curated ML reference set: 61 tobamoviral + 27 outgroup
  sequences (`reference_database.xlsx`, `reference_nukleotidne.fasta`) and
  the four reference ORF protein sequences used for pairwise alignment
  (`all_proteins.fasta`).
- **`references/`** — the workflow that builds `tobamo/reference_database.xlsx`
  and the non-Virgaviridae control set, merged in from the original
  `analysis/references/` folder. See `references/README.md`.
